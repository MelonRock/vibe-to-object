# Vibe to Object

把说不出的感觉，变成拿在手里的东西。

用户上传一张对自己有意义的照片，从几种画面里挑一个最像自己的风格。AI 把照片重新画成一幅画，印在手机壳上。目标只有一个：用户看到时会说"这就是我"。

第一阶段做手机壳，以后再做更多物品。

## 流程

上传照片 → 选风格 → 出图 → 人脸比对 → 放大校色 → 机型排版 → 预览 → 下单

## 架构

| 模块 | 做什么 | 工具 |
|---|---|---|
| 上传把关 | 测清晰度和人脸大小，糊图当场拦下 | OpenCV |
| 出图 | 按风格把任务分给评测分数最高的模型 | Gemini、Flux Kontext |
| 主体分割 | 分清每个人和每只宠物，核对数量 | SAM 2 |
| 人脸比对 | 和原照片比相似度，不够就重出 | AWS Rekognition |
| 肤色校验 | 在 Lab 色彩空间算 ΔE，防止肤色被画浅 | OpenCV |
| 放大校色 | 放大到 300 DPI，按打印厂 ICC 配置软打样 | Real-ESRGAN、LittleCMS |
| 镜头避让 | 脸碰到开孔或裁切线就重新构图 | MediaPipe、机型模板 |
| 任务队列 | 排队、重试、控制成本 | Celery、Redis |
| 预览下单 | 出实物预览图，自动下单，回传物流 | Printful API、webhook |
| 隐私 | 照片加密存储，30 天后自动删除 | S3、KMS |

## 路线图

- 第 1 周：20 张真照片 × 3 种风格测试，打 3 个实物样
- 第 2 周：手动接单，跑通第一单
- 第 3–4 周：用 Devin 把跑顺的手动步骤换成自动

## 衡量

- 预览一次通过率
- 重印和退款率
- 前 10 单的好评数

## 说明

风格模板不公开。顾客照片只用于完成订单，不用于训练模型。
