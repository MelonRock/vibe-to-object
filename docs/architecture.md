# 架构说明

## 数据流

1. 上传：顾客上传照片，先过上传把关（src/quality_gate.py）。
2. 出图：按所选风格生成 4 个版本。
3. 校验：人脸比对、肤色校验、人数核对。
4. 排版：按机型模板放大、校色、加出血，检查镜头避让（src/camera_safe_zone.py）。
5. 预览：生成实物预览图，顾客确认。
6. 下单：确认后提交打印厂订单，物流状态回传。

## 任务状态

uploaded → checked → generating → reviewing → print_ready → previewed → ordered → shipped

任何一步失败，就回到上一步重做。最多重试 3 次，之后转人工处理。

## 阈值（初始值，按评测集调整）

| 检查 | 规则 |
|---|---|
| 清晰度 | 拉普拉斯方差 ≥ 100 |
| 人脸大小 | 最小人脸边长 ≥ 照片短边的 12% |
| 人脸比对 | 相似度 ≥ 90 |
| 肤色色差 | ΔE ≤ 6 |
| 镜头避让 | 人脸框不得进入镜头区和裁切区 |

## 机型模板

每个机型一个 JSON 文件，写明画布尺寸、裁切边距和镜头开孔区域（按画布比例）。默认模板见 templates/default.json。

## 隐私

照片加密存储，30 天后自动删除。风格模板不在本仓库。
